## 2. What is JavaScript?

A programming language mainly used to make web pages interactive. It runs in the browser, and on servers with Node.js.

## 3. What three problems does Git & GitHub solve?

1. Working on different versions of the same repo and file simultaneously; branches let you work on separate versions of the code at the same time without breaking the main version.
2. Different people on the same project/repo simultaneously; on their small part while leaving other parts alone. GitHub handles storing the code online (a backup you can reach from any computer) and sharing and reviewing code through pull requests.
3. Having version history so you can go back

## 4. What happens when you `fork` a repository?

It creates your own copy of someone else's repository on GitHub, under your account. You can change it freely without affecting the original, and still open pull requests back to it.

## 5. What happens when you clone a repository?

It downloads a copy of the repository, including its full history, from GitHub to your computer so you can work on it locally.

## 6. What is a Pull Request?

A request to merge the changes from one branch into another, so others can review and discuss them before they are merged.
